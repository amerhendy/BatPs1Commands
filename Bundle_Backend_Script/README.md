
# دليل استخدام وتوثيق سكريبت تجميع ملفات مشروع الباك إند (Backend Bundle Script)

## 1. وصف الملف ووظيفته (Overview)
هذا السكريبت مكتوب بلغة **PowerShell** وتتلخص وظيفته الأساسية في تجميع ومجمل محتويات مجموعة محددة من ملفات البرمجة (Python files) الخاصة بنظام **Backend** (مثل Models, Schemas, Services, Repositories, Routes, Enums). 

يقوم السكريبت بقراءة الملفات المحددة في مصفوفة (`$files`) وتجميع نصوصها بالكامل في ملف نصي واحد باسم `backend_bundle.txt` يفصل بين كل ملف والآخر باستخدام ترميز **UTF-8** لضمان حفظ الأحرف بشكل صحيح.

---

## 2. المتطلبات الأساسية (Prerequisites)

* **بيئة التشغيل:**
  * نظام تشغيل Windows مفعل عليه **PowerShell 5.1** أو **PowerShell Core (v7+)**.
  * وجود صلاحيات القراءة على المجلدات والملفات المحددة.
  * **سياسة التنفيذ (Execution Policy):** يجب السماح بتشغيل السكريبتات على الجهاز.

* **موقع التشغيل ومسارات الملفات (Working Directory Location):**
  * **هل يشتغل من نفس الفولدر أم فولدر مختلف؟**
    * **قراءة الملفات المصدر:** يقرأ من **أي فولدر** لأن المسار الأساسي للمشروع مدون بمسار مطلق (`Absolute Path`) داخل المتغير `$base` (`C:\Users\sinaiwater\...`).
    * **إخراج الملف الناتج:** يحفظ ملف النتيجة `backend_bundle.txt` في **نفس الفولدر الذي يتم تنفيذ الأوامر منه (Current Directory)**. إذا أردت حفظ الناتج في مكان محدد، يمكن تغيير مسار حفظ الملف في السطر الأخير.

> **ملاحظة مهمة:** السكريبت يحتوي على مسار ثابت (`$base`) خاص بجهاز معين (`C:\Users\sinaiwater\...`). يجب تعديل مسار `$base` ليتناسب مع جهازك قبل التشغيل لضمان العثور على الملفات.

---

## 3. طريقة التشغيل (Usage Instructions)

1. افتح نافذة **PowerShell** أو **Terminal**.
2. احفظ الكود أعلاه في ملف بملحق `.ps1` (مثال: `bundle_backend.ps1`).
3. انقُل النافذة إلى المجلد الذي تريد حفظ ملف النتيجة فيه أو قم بالتشغيل المباشر.
4. نفذ السكريبت باستخدام الأمر الموضح في قسم الأمان أدناه.
5. بعد انتهاء التنفيذ، ستجد ملفاً جديداً باسم `backend_bundle.txt` يحتوي على جميع الملفات المجمعة.

---

## 4. الأمان وأوامر التشغيل (Security & Execution Code)

### مراجعة الأمان (Security Review):
* السكريبت **آمن تماماً ولا يشكل أي خطورة**؛ حيث يقتصر عمله على عمليات قراءة الملفات (`Get-Content`) وإخراجها في ملف نصي (`Out-File`).
* لا يحتوي السكريبت على أي أوامر حذف، تعديل على نظام التشغيل، أو اتصال بالشبكة.

### كود التشغيل الآمن (Execution Command):

يمكنك تشغيل السكريبت من خلال PowerShell مباشرة باستخدام الأمر التالي مع تعديل سياسة التنفيذ للجلسة الحالية فقط دون التأثير على أمان النظام العام:

```powershell
powershell -ExecutionPolicy Bypass -File .\bundle_backend.ps1
```

أو إذا كنت تعمل داخل نافذة PowerShell مفتوحة بالفعل:

```powershell
Set-ExecutionPolicy -ExecutionPolicy Process -Scope Process
.\bundle_backend.ps1
```
