
# توثيق سكربت النسخ الاحتياطي (`backup.sh`)

## 1. فكرة وحاجة السكربت (Explanation)
هذا السكربت عبارة عن **Bash Script** مخصص لقواعد بيانات **PostgreSQL**. يقوم بعمل نسخة احتياطية (Backup) لقاعدة بيانات معينة واستخراجها على هيئة ملف SQL، ويحتوي اسم الملف افتراضياً على التاريخ والوقت لتمييز النسخ الاحتياطية المختلفة.

---

## 2. المتطلبات (Prerequisites)

- **البرامج والخدمات:**
  - نظام تشغيل قائم على Linux / Unix أو بيئة Bash (مثل WSL على Windows).
  - تثبيت أدوات PostgreSQL العميلة (أهمها أداة `pg_dump`).
  - تشغيل خادم PostgreSQL وإمكانية الوصول إليه.

- **بيئة التشغيل ومكان التنفيذ (Working Directory):**
  - **من أي فولدر (مختلف):** يمكن تشغيل هذا السكربت من أي مسار داخل النظام بشرط تحديد المسار الكامل للسكربت وللملف الناتج، أو ترك السكربت ليحفظ في المسار الافتراضي المحدد داخله (`/shared/`).
  - **ملاحظة صلاحيات:** يجب التأكد من وجود صلاحية الكتابة (Write Permission) في مجلد الحفظ (`/shared/` أو المجلد المختار).

---

## 3. طريقة التشغيل والاستخدام (How to Run)

### الصيغة العامة:
```bash
./backup.sh <database_name> <output_file>
```

### أمثلة على التشغيل:

1. **التشغيل الافتراضي (بدون مدخلات):**
   *(سيقوم بعمل نسخة لقاعدة البيانات `postgres` ويحفظها في `/shared/` باسم يحتوي على التاريخ والوقت)*
   ```bash
   ./backup.sh
   ```

2. **تحديد اسم قاعدة البيانات فقط:**
   ```bash
   ./backup.sh my_database
   ```

3. **تحديد اسم قاعدة البيانات ومسار الحفظ:**
   ```bash
   ./backup.sh my_database /path/to/my_backup.sql
   ```

4. **تغيير إعدادات الاتصال (عبر متغيرات البيئة):**
   ```bash
   DB_HOST="192.168.1.100" DB_PORT="5433" DB_USER="admin" ./backup.sh my_database
   ```

---

## 4. الأمان وتنفيذ الكود (Security & Execution)

### إعطاء صلاحية التنفيذ (Execution Permissions):
قبل تشغيل السكربت لأول مرة، يجب منح السكربت صلاحية التنفيذ باستخدام الأمر:
```bash
chmod +x backup.sh
```

### أمر التشغيل المباشر والآمن:
```bash
./backup.sh
```

### ملاحظات وتنبيهات أمنية:
1. **كلمة المرور:** لا يحتوي السكربت على كلمة سر للاتصال بقاعدة البيانات. يُفضل ضبط ملف `~/.pgpass` أو استخدام متغير البيئة `PGPASSWORD` بأمان لتجنب طلب كلمة المرور تفاعلياً.
2. **صلاحيات القراءة:** السكربت يستخدم أداة `pg_dump`؛ يجب أن يمتلك المستخدم (`DB_USER`) صلاحيات قراءة كافية للبيانات والجداول المراد نسخها.
