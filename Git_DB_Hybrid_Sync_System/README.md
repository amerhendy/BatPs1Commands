
# دليل سكريبت تصدير قاعدة البيانات والرفع إلى GitHub

## 1. الوصف والشرح (Description)
هذا السكريبت عبارة عن أداة تلقائية لأخذ نسخة احتياطية من قاعدة بيانات PostgreSQL تعمل داخل حاوية Docker، ثم إيقاف بيئة العمل، ورفع آخر التعديلات مع النسخة الاحتياطية إلى المستودع (Repository) على GitHub.

### الخطوات التي ينفذها السكريبت:
1. **البحث عن الحاوية:** يحدد تلقائياً اسم حاوية Docker الخاصة بقاعدة بيانات PostgreSQL التي تحتوي كلمتها على `postgres`.
2. **طلب بيانات الاعتماد:** يطلب من المستخدم إدخال اسم المستخدم، اسم قاعدة البيانات، وكلمة المرور.
3. **تصدير قاعدة البيانات:** ينشئ مجلداً باسم `db_sync` (إن لم يكن موجوداً) ويقوم بعمل `pg_dump` وحفظ النتيجة في `latest_db.sql`.
4. **إيقاف الحاويات:** ينفذ أمر `docker compose down` لإيقاف البيئة بشكل آمن.
5. **الرفع إلى GitHub:** يضيف التغييرات (`git add .`)، ويقوم بعمل Commit برسالة محددة بالتاريخ والوقت الحالي، ثم يدفع التغييرات (`git push origin main`).

---

## 2. المتطلبات (Requirements & Prerequisites)

* **البرامج المطلوبة:**
  * **Docker / Docker Desktop** يعمل على الجهاز.
  * **Git** مثبت ومربوط بـ GitHub.
  * حاوية PostgreSQL شغالة تحتوي في اسمها على كلمة `postgres`.
* **بيئة التشغيل:**
  * **يجب تشغيل الملف من نفس فولدر المشروع الأساسي** (أي الفولدر الذي يحتوي على ملف `docker-compose.yml` والـ Git Repository)، وذلك حتى يتم إنشاء مجلد `db_sync` وتنفيذ أوامر Git في مكانها الصحيح.

---

## 3. طريقة التشغيل والأمان (Usage & Execution)

### كيفية التشغيل من موجه الأوامر (CMD):
قم بفتح موجه الأوامر داخل فولدر المشروع ثم نفذ الأمر التالية:

```cmd
export_db_and_push.bat
```

أو يمكنك النقر المزدوج (Double Click) على الملف إذا كنت تواجه المجلد مباشرة.

### ملاحظات أمان:
* السكريبت يقوم بإرسال كلمة المرور عبر المتغير الموقت `PGPASSWORD` أثناء تنفيذ أمر `docker exec` لضمان عدم بقائها مكشوفة في سجل النظام.
* تأكد من عدم رفع ملفات التصدير الحساسة إلى مستودعات GitHub العامة (Public Repositories) إذا كانت تحتوي على بيانات سرية.
