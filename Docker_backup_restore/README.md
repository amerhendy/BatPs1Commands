
# دليل استخدام وأمان سكربتات مزامنة Docker (Windows)

هذا المستند يشرح مجموعة السكربتات المخصصة لمزامنة بيئة عمل Docker بين جهازين (مثل جهاز المنزل وجهاز العمل) باستخدام أقراص USB أو مساحات التخزين الخارجية.

---

## 1. السكربت الأول: `sync-both.bat` (Master Sync Control)

### 📝 الوصف والتوضيح
هو السكربت الرئيسي والتحكم الموحد (Master Script) للعملية بأكملها. يتيح لك تنفيذ العمليات بسهولة من خلال خيارات بسيطة دون الحاجة لمعرفة التفاصيل الداخلية لسكربتات النسخ والاسترجاع.

**المهام الرئيسية:**
- تفعيل ألوان ANSI في موجه الأوامر (Windows 10+).
- عرض حالة بيئة Docker الحالية (الحاويات، الأحجام/Volumes، والصور/Images).
- استدعاء سكربت النسخ الاحتياطي (`docker-backup.bat`).
- البحث عن أحدث نسخة احتياطية واستدعاء سكربت الاسترجاع (`docker-restore.bat`).

---

### 📋 المتطلبات المسبقة ومسار التشغيل
* **نظام التشغيل**: Windows 10 أو أحدث (لتدعم ألوان ANSI واسترجاع المسارات القصيرة 8.3).
* **البرامج المطلوبة**: Docker Desktop مثبّت ويعمل.
* **مسار التشغيل**: 
  * **يجب تشغيله من نفس فولدر المشروع** (Current Directory) للعمل بشكل صحيح، حيث يتوقع وجود فولدر `.docker-backup\` في نفس المسار.

---

### 🔒 طريقة التشغيل والأمان

يمكن تشغيله مباشرة عبر **Command Prompt (CMD)** أو **PowerShell**:

#### 1. عرض خيارات الاستخدام والشرح:
```cmd
sync-both.bat
```

#### 2. عرض حالة Docker الحالية:
```cmd
sync-both.bat status
```

#### 3. إنشاء نسخة احتياطية:
```cmd
sync-both.bat backup
```

#### 4. استرجاع أحدث نسخة احتياطية:
```cmd
sync-both.bat restore
```

## 2. السكربت الثاني: `docker-backup.bat` (Backup Script)

### 📝 الوصف والتوضيح
هذا السكربت مخصص للعمل على الجهاز المصدر (مثل جهاز المنزل). يقوم بأخذ لقطة كاملة (Snapshot) لبيئة العمل وحفظها داخل مجلد `.docker-backup`.

**المهام الرئيسية:**
- إنشاء مجلد بحسب التاريخ والوقت لتفادي مسح النسخ القديمة.
- نسخ ملفات الإعدادات: `docker-compose.yml` و `Dockerfile`.
- نسخ الكود المصدري للمشروع باستخدام `robocopy` مع استبعاد المجلدات غير الضرورية (`.git`, `node_modules`, `.venv`, إلخ).
- عمل استخراج وتصدير (Export) لبيانات الـ Docker Volumes المربوطة باستخدام صورة `alpine` مصغرة.
- تسجيل حالة الحاويات (Container States) وإنشاء ملف بيان النسخة (`MANIFEST.txt`).

---

### 📋 المتطلبات المسبقة ومسار التشغيل
* **البرامج المطلوبة**: 
  * Docker Desktop (يجب أن يكون شغالاً لسحب الـ Volumes).
  * أداة `robocopy` (مدمجة تلقائياً في ويندوز).
  * صورة `alpine` للـ Docker (سيتم سحبها تلقائياً إذا لم تكن موجودة).
* **مسار التشغيل**:
  * **يجب تشغيله من داخل مجلد المشروع المراد أخذ نسخة منه** (Current Directory)، أو تمرير اسم المجلد كـ Argument.

---

### 🔒 طريقة التشغيل والأمان

يمكن استدعاؤه بشكل مباشر أو عبر السكربت الرئيسي `sync-both.bat backup`.

#### التشغيل المباشر من CMD/PowerShell:
```cmd
docker-backup.bat
```

#### أو تحديد مجلد حفظ مخصص:
```cmd
docker-backup.bat "D:\MyBackups"
```

## 3. السكربت الثالث: `docker-restore.bat` (Restore Script)

### 📝 الوصف والتوضيح
هذا السكربت مخصص للعمل على الجهاز الهدف (مثل جهاز العمل). يقوم باسترجاع بيئة العمل والدمج الذكي مع الملفات الحالية.

**المهام الرئيسية:**
- التأكد من وجود ملف البيان `MANIFEST.txt` للتحقق من صحة النسخة.
- إنشاء **نسخة احتياطية آمنة تلقائية** للوضع الحالي قبل أي تعديل (`.docker-backup-safety-*`).
- إيقاف الحاويات الشغالة بأمان.
- استبدال أو تحديث ملفات `Dockerfile` و `docker-compose.yml`.
- مزامنة كود التطبيق بدون مسح الملفات المحلية الأخرى.
- دمج واسترجاع بيانات الـ Volumes داخل Docker.
- إعادة بناء الصور تشغيل الحاويات مجدداً بـ (`docker-compose up -d`).

---

### 📋 المتطلبات المسبقة ومسار التشغيل
* **الصلاحيات**: ينصح بتشغيله كـ **مسؤول (Administrator)** لويندوز للتمكن من التعديل في إعدادات الترميز والألوان بحرية.
* **البرامج المطلوبة**: Docker Desktop + Docker Compose.
* **مسار التشغيل**:
  * **يمكن تشغيله من فولدر المشروع الحالي أو فولدر مختلف**، بشرط تمرير المسار الكامل لمجلد النسخة الاحتياطية كـ (Parameter).

---

### 🔒 طريقة التشغيل والأمان

#### التشغيل مع تحديد مسار مجلد النسخة الاحتياطية:
```cmd
docker-restore.bat ".docker-backup\backup_20260919_150000"
```

#### التشغيل إذا كان المجلد يحتوي على مسافات:
```cmd
docker-restore.bat "C:\My Backups\backup_20260919_150000"
```

---

## 🛡️ ملخص الأمان وأفضل الممارسات

1. **النسخ الآمن (Safety Net)**: يقوم سكربت الاسترجاع تلقائياً بإنشاء نقطة استعادة قبل التعديل، مما يضمن عدم فقدان أي بيانات على جهاز العمل.
2. **التعامل مع المسافات في المسارات**: السكربتات تعالج المسارات التي تحتوي على مسافات باستخدام أسماء `8.3` المباشرة لتجنب توقف التنفيذ في نظام ويندوز.
3. **عدم تسريب الملفات الحساسة**: يتم استثناء المجلدات الإفتراضية أو البيئات الافتراضية مثل `.venv` و `node_modules` و `.git` لتخفيف حجم النسخة الاحتياطية وتسريع العملية.
