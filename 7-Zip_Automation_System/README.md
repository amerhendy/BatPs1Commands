
# دليل سكريبت النسخ الاحتياطي التفاعلي (Interactive Backup Script)

## 1. الوصف والعرض العام
هذا السكريبت عبارة عن أداة Batch بسيطة وتفاعلية لتسهيل عملية إنشاء نسخ احتياطية مضغوطة للمجلدات بصيغة `7z`. 
يقوم السكريبت بالتغاضي عن مجلدات التطوير المؤقتة الكبيرة (مثل `node_modules` و`venv` و`__pycache__` و`.pytest_cache`) لتقليل حجم النسخة الاحتياطية وتوفير المساحة وسرعة الضغط.

---

## 2. المتطلبات الأساسية (Prerequisites)

* **صلاحيات التشغيل:** 
  * يشتغل بصلاحيات **المستخدم العادي (Standard User)**. 
  * يتطلب صلاحيات **المسؤول (Administrator)** فقط في حال كانت المجلدات المراد ضغطها توجد داخل مسارات تحميها صلاحيات النظام (مثل `C:\Program Files`).
* **البرامج المطلوبة:** 
  * برنامج **7-Zip** مثبت على الجهاز، ومعرفة مسار الملف التنفيذي `7z.exe` (غالباً يكون في: `C:\Program Files\7-Zip\7z.exe`).
* **موقع ومسار التشغيل:**
  * **يمكن تشغيله من أي فولدر (مستقل عن المسار):** لا يشترط وجود السكريبت داخل المجلد المراد ضغطه، حيث يسمح بتحديد مسار المجلد المستهدف تفاعلياً أو تمريره كبرامتر أثناء التشغيل.

---

## 3. طريقة التشغيل (How to Run)

### الطريقة الأولى: التشغيل التفاعلي (Double Click)
1. قم بالنقر المزدوج على الملف `backup.bat`.
2. ادخل مسار المجلد الذي تريد أخذ نسخة احتياطية منه عندما يطلب منك السكريبت ذلك.
3. ادخل مسار برنامج `7z.exe` (مثال: `C:\Program Files\7-Zip\7z.exe`).
4. سيتم ضغط المجلد وإنشاء الأرشيف في نفس مسار المجلد المستهدف.

### الطريقة الثانية: التشغيل عبر موجه الأوامر (CMD) مع تمرير البرامتر
يمكنك تمرير مسار المجلد مباشرة كبرامتر أول أثناء التشغيل:
```cmd
backup.bat "C:\Users\Name\Projects\MyProject"
```

---

## 4. أمان التشغيل وسياسات التنفيذ (Execution Security Policy)

بما أن الملف ذو امتداد `.bat` فهو ينفذ مباشرة عبر **CMD (Command Prompt)** بدون سياسات أمان معقدة. أما في حالة تشغيله من داخل بيئة **PowerShell**، يمكنك استخدامه كالتالي:

* **لتشغيله داخل PowerShell بشكل مباشر:**
  ```powershell
  Start-Process cmd.exe -ArgumentList "/c C:\path\to\backup.bat"
  ```
* **في حال الحاجه لتغيير سياسة صلاحيات PowerShell للجلسة الحالية:**
  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
  ```

---

## 5. شرح أجزاء الكود والأوامر

```bat
@echo off
```
إخفاء طباعة الأوامر نفسها في الشاشة أثناء التنفيذ لتسهيل قراءة المخرجات.

```bat
set "TARGET=%~1"
```
تخزين البرامتر الأول الممرر للسكريبت في متغير اسمه `TARGET` (مع إزالة علامات التنصيص المحيطة به إن وجدت بواسطة `%~1`).

```bat
if "%TARGET%"=="" (
    set /p "TARGET=Enter the directory path to backup: "
)
if "%TARGET%"=="" exit
```
التحقق مما إذا كان متغير `TARGET` فارغاً (لم يتم تمرير برامتر). في حال كان فارغاً، يطلب السكريبت من المستخدم إدخال المسار تفاعلياً. وإذا تركها المستخدم فارغة يغلق السكريبت.

```bat
set /p "ZIP_PATH=Enter full path to 7z.exe (e.g. C:\Program Files\7-Zip\7z.exe): "
```
طلب مسار برنامج `7-Zip` التفاعلي من المستخدم وتخزينه في المتغير `ZIP_PATH`.

```bat
set "ZIP_PATH=%ZIP_PATH:"=%"
```
معالجة النص المقروء وإزالة أي علامات تنصيص إضافية (`"`) قد يضيفها المستخدم بالخطأ عند نسخ المسار ولصقه.

```bat
if not exist "%ZIP_PATH%" (
    echo Error: 7z.exe was not found at the specified path.
    pause
    exit /b
)
```
التحقق من وجود برنامج `7z.exe` في المسار المحدد. في حال عدم وجوده، يتم إظهار رسالة خطأ وإيقاف التنفيذ.

```bat
cd /d "%TARGET%"
```
الانتقال إلى مسار المجلد المراد ضغطه (استخدام الخيار `/d` للتمكن من تغيير القرص/Drive إذا كان المجلد في بارتيشن مختلف).

```bat
"%ZIP_PATH%" a -t7z "%TARGET%.7z" "*" -xr!.pytest_cache -xr!__pycache__ -xr!venv -xr!node_modules
```
أمر الضغط الخاص بـ 7-Zip:
* `a`: أمر إضافة المجلدات للأرشيف (Add).
* `-t7z`: تحديد نوع الضغط بـ 7z.
* `"%TARGET%.7z"`: اسم ومسار الملف المضغوط الناتج.
* `"*"`: ضغط جميع محتويات المجلد الحالية.
* `-xr!...`: استثناء ومسح المجلدات الفرعية غير المرغوب بها من الضغط مثل `node_modules` و`venv`.

```bat
pause
```
إيقاف الشاشة مؤقتاً لتسهيل رؤية نتيجة العملية قبل إغلاق النافذة.

---

## 6. ملاحظات وتحذيرات

1. **الاستثناءات:** الملف يستثني المجلدات الخاصة بـ Python و Node.js (`venv`, `node_modules`, إلخ). إذا كنت تريد ضغط هذه المجلدات، قم بتعديل السكريبت وإزالة خيارات `-xr!`.
2. **المسارات التي تحتوي على مسافات:** احرص دائماً على وضع المسارات بين علامات تنصيص `""` عند التمرير لتجنب أخطاء توقف السكريبت.
3. **حجم الملف المخرَج:** الملف المضغوط سيتم إنشاؤه في نفس المجلد الأب للمجلد المستهدف وبنفس اسمه مضافاً إليه الامتداد `.7z`.


# دليل سكريبت النسخ الاحتياطي للمشروع (Project Local Backup Script)

## 1. الوصف والعرض العام

هذا السكريبت عبارة عن أداة Batch سريعة ومصممة لعمل نسخة احتياطية سريعة للمشروع الحاضر داخل نفس المجلد. يقوم بضغط جميع محتويات المجلد الحالي إلى أرشيف باسم `project_backup.7z` مع استثناء المجلدات والملفات المؤقتة الخاصة ببيئات التطوير (مثل `node_modules` و `venv` و `__pycache__` و `.pytest_cache`).

## 2. المتطلبات الأساسية (Prerequisites)

* **صلاحيات التشغيل:**
  * يعمل بصلاحيات **المستخدم العادي (Standard User)**.
  * يحتاج صلاحيات **المسؤول (Administrator)** فقط إذا كان المشروع في مجلد يتطلب صلاحيات قراءة/كتابة خاصة بالنظام.

* **البرامج المطلوبة:**
  * برنامج **7-Zip** مثبت على الجهاز، ومعرفة المسار الكامل لملف `7z.exe` (عادة يكون في: `C:\Program Files\7-Zip\7z.exe`).

* **موقع ومسار التشغيل:**
  * **يجب تشغيله من نفس المجلد (مسار نسبي):** هذا السكريبت مصمم ليتم وضعه وتشيغله **داخل المجلد الخاص بالمشروع المراد ضغطه حصراً**؛ لأنه يقوم بضغط كل المحتويات الموجودة بنفس المجلد المتواجد فيه حالياً (`*`).

## 3. طريقة التشغيل (How to Run)

### التشغيل عبر النقر المزدوج (Double Click)

1. انقُل الملف `project_backup.bat` واضعه داخل المجلد الرئيسي لمشروعك.
2. قم بالنقر المزدوج على الملف `project_backup.bat`.
3. اكتب أو قم بلصق المسار الكامل لملف `7z.exe` واضغط على **Enter**.
4. سيبدأ البرنامج بضغط كافة محتويات المجلد واستثناء ملفات التطوير الثقيلة، وسينتج ملف باسم `project_backup.7z` في نفس الفولدر.

## 4. أمان التشغيل وسياسات التنفيذ (Execution Security Policy)

بما أن الملف بصيغة Batch (`.bat`)، فهو يعمل عبر **CMD (Command Prompt)** بشكل مباشر دون قيود سياسات التنفيذ الخاص بـ PowerShell. أما في حال رغبت بتشغيله عبر بيئة **PowerShell**:

* **كود التشغيل المباشر من داخل PowerShell:**
  ```powershell
  Start-Process cmd.exe -ArgumentList "/c project_backup.bat"
  ```

* **تغيير سياسة الصلاحيات لجلسة PowerShell الحالية (إن لزم الأمر):**
  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
  ```

## 5. شرح أجزاء الكود والأوامر

```bat
@echo off
```
يخفي طباعة الأوامر المكتوبة على الشاشة أثناء التنفيذ لتنسيق المخرجات.

```bat
set /p "ZIP_PATH=Enter full path to 7z.exe (e.g. C:\Program Files\7-Zip\7z.exe): "
```
يطلب من المستخدم إدخال المسار الكامل لبرنامج `7z.exe` وتخزينه في المتغير `ZIP_PATH`.

```bat
set "ZIP_PATH=%ZIP_PATH:"=%"
```
يقوم بتنقية وتصفية النص المقروء وإزالة علامات التنصيص المزدوجة `"` في حال قام المستخدم بنسخ المسار ومعه علامات تنصيص لتجنب أخطاء المسارات.

```bat
if not exist "%ZIP_PATH%" (
    echo Error: 7z.exe was not found at the specified path.
    pause
    exit /b
)
```
يتأكد من وجود الملف التنفيذي لـ 7-Zip في المسار المحدد، وفي حال عدم وجوده يظهر رسالة خطأ ويوقف السكريبت.

```bat
"%ZIP_PATH%" a -t7z project_backup.7z * -xr!.pytest_cache -xr!__pycache__ -xr!venv -xr!node_modules
```
أمر تشغيل الضغط الخاص بـ 7-Zip:
* `a`: إيعاز إنشاء وتحديث الأرشيف (Add).
* `-t7z`: تحديد صيغة الضغط لتكون 7z.
* `project_backup.7z`: اسم ملف النسخة الاحتياطية الناتج.
* `*`: تحديد كافة الملفات والمجلدات الموجودة في المسار الحالي لضغطها.
* `-xr!...`: استثناء المجلدات والملفات المؤقتة الخاصة بـ Node.js و Python لتوفير المساحة وسرعة الضغط.

```bat
pause
```
يقوم بإيقاف الشاشة مؤقتاً لتتمكن من مراجعة النتيجة قبل إغلاق النافذة.

## 6. ملاحظات وتحذيرات

1. **الكتابة فوق الملف القديم:** إذا قمت بتشغيل السكريبت أكثر من مرة في نفس المجلد وكان الملف `project_backup.7z` موجوداً بالفعل، سيقوم 7-Zip بتحديث الملف وإضافة/تحديث الملفات التالفة أو المحدثة داخل الأرشيف.
2. **مكان الحفظ:** الملف المضغوط الناتج `project_backup.7z` سينتج داخل نفس المجلد.
3. **تغيير قائمة الاستثناءات:** يمكنك فتح الملف بواسطة أي محرر نصوص لتغيير المجلدات المستثناة بعد خيار `-xr!`.
